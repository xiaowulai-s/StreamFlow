# Z

多平台直播聚合观看：**虎牙 / 斗鱼 / B站 / 抖音 / 快手**——站内播放、只读弹幕、关注管理，本地运行不依赖任何服务端。

> 当前版本 v0.0.1 · Tauri 2 + React · Windows 10/11（需 WebView2 Runtime）

## 安装

两种方式（见 GitHub Releases）：

- **MSI 安装包**：`Z_0.0.1_x64_en-US.msi`，双击安装
- **便携版**：`z-0.0.1-portable.exe`，单文件直接运行

## 功能总览

| 功能 | 说明 |
|---|---|
| 全网搜索 | 顶栏输入关键词回车，跨五平台搜索；平台筛选 + 热度/开播时间排序 |
| 站内播放 | HLS/FLV 原生流（无广告注入）；画质切换（快手/斗鱼/B站 多档，默认免费最高档） |
| 只读弹幕 | B站/斗鱼/虎牙/抖音/快手 弹幕实时显示，不发送、不注入任何平台 |
| 我的关注 | 直播间内收藏 + 各平台关注列表一键导入；按平台展示开关（可隐藏不看的平台） |
| 观看历史 | 自动记录，支持保留期限（永久/7/30/90 天） |
| 登录管理 | B站/斗鱼/虎牙/快手/抖音 内嵌官方页面登录；会话仅存本机 |
| 登录态迁移 | 导出登录态文件 → 新设备导入，免重复登录 |
| 双主题 | 跟随系统 / 浅色 / 深色 |

## 快速上手

1. **登录平台**（可选，影响关注导入与部分搜索）：设置中心 → 对应平台「扫码登录」（B站/斗鱼/快手）或「内嵌登录」（虎牙/抖音）
2. **搜索或导入关注**：顶栏搜索直接看；或关注页点「同步平台关注」导入各平台已关注主播
3. **观看**：点击卡片进入播放页——画质切换在播放器右上角，弹幕在右侧栏，音量/静音/外部打开在底部操作条
4. **开播提醒**：首页「关注开播」条展示已关注主播的直播状态

## 设置中心

- **平台接入**：各平台登录/退出、启用停用（停用不参与搜索）、连通检测（门户 + 接口级健康验证）
- **关注展示开关**：按平台隐藏其关注内容（关注页/首页/计数联动）
- **外观**：主题三选一
- **播放设置**：音量记忆（自动）、默认静音、卡片点击默认打开方式（站内/外部浏览器）
- **数据与隐私**：登录态导出/导入、清理网页缓存（会清除登录态）、历史保留期限
- **关于**：版本信息、检查更新

## 应用内自更新

设置中心 → 关于 → 「检查更新」：从更新源拉取版本信息，签名验证通过后自动下载安装并重启。

> 当前仓库为私有，应用内检查更新不可用——请到 GitHub Releases 页手动下载新版本；仓库转公开后自动恢复。

## 数据与隐私

- 登录会话（cookie）仅保存在本机应用数据目录，不经过任何第三方
- 收藏/历史/设置存于本机 SQLite（`streamflow.db`）
- 弹幕只读，不发送、不注入、不代发任何内容
- 退出登录立即清除本机会话；平台官网改密码也会使其失效

## 已知限制

- **抖音**：搜索/关注导入需登录态且受风控限制（当前返回空数据）；热门列表被风控拦截；播放/弹幕/详情不受影响
- **快手**：热门榜单受 TLS 指纹风控降级（搜索/播放/弹幕不受影响）
- **抖音登录**：登录窗口内需完成扫码/验证码，属平台安全要求
- 签名/风控方案随平台更新可能失效，属持续维护项

## 开发

```bash
# 前端
cd frontend && npm install && npm run build

# 后端（必须 custom-protocol，否则白屏）
cd src-tauri && cargo build --release --features custom-protocol

# 产物
# src-tauri/target/release/streamflow.exe（便携）
# src-tauri/target/release/bundle/msi/*.msi（安装包）
```

技术栈：Tauri 2 + React 19 + Rust（reqwest/tokio/sqlx）+ hls.js + mpegts.js。
