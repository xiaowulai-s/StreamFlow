# 集成风险（integration_risks.md）

## 架构风险
| 风险 | 触发条件 | 影响 | 缓解 |
|---|---|---|---|
| 平台协议变更导致适配器失效 | 平台改 Web 端协议（历史已发生：抖音搜索/快手 TLS） | 单平台功能退化 | ① 失效监测已覆盖根因提示 ② DTV/real-url 协议对照源（MIT）③ webctx 页面环境路线对风控升级更耐受 |
| webctx 隐藏窗口被平台风控识别 | 页面环境请求频率过高 | 搜索/关注/热门退化 | 请求频率已有节制；加退避即可 |
| 弹幕重连实现不当造成风暴 | 下播房间无限重连 | 资源浪费 | 重连循环需检测 status（下播即停）——OPP-1 验证项 |

## 性能风险
| 风险 | 说明 | 缓解 |
|---|---|---|
| 多开播放软解压力 | hls.js/mpegts.js 软解，多窗口内存/CPU 线性增长 | 当前单窗口设计规避；多开需求出现时按 OPP-12 评估 |
| 飘屏 DOM 压力 | 密度上限已防；CSS transform GPU 合成 | 已验证 |
| 前端 Context 全量重渲 | 巨型 Context 任意 setState 全树重渲 | 当前页面树规模无实测卡顿；卡片 memo 已有；必要时拆 context |

## 安全风险
| 风险 | 说明 | 缓解 |
|---|---|---|
| 平台 cookie 本地存储 | 登录态明文存于应用数据目录 | 同类产品通行做法；导出功能已提示敏感 |
| updater 供应链 | latest.json 端点双通道（github 直链+jsdelivr） | 签名验证强制 ✓；私钥本地未入库 ✓ |
| 依赖漏洞 | 未自动化审计 | 建议 cargo-deny 进 CI（OPP-10） |
| 反向工程边界 | 平台无官方 API，协议重建 | 「仅供学习」声明已含；不做主动攻击行为（限频/退避已落实） |
